⏺ The dual-condition gate is in place. Here's how the evaluation logic now
  works:

  ┌──────────────┬──────────────────┬───────────────────────────────────────┐
  │  Post type   │    Condition     │               Treatment               │
  ├──────────────┼──────────────────┼───────────────────────────────────────┤
  │ Winner       │ likes > 1 AND    │ reinforcement=1 · fed back as style   │
  │              │ final_score ≥ 65 │ templates                             │
  ├──────────────┼──────────────────┼───────────────────────────────────────┤
  │ Engagement   │ likes > 1 BUT    │ reinforcement=0 · agent sees it in    │
  │ bait         │ final_score < 65 │ engagement_bait with note: "study the │
  │              │                  │  hook, not the content"               │
  ├──────────────┼──────────────────┼───────────────────────────────────────┤
  │ Pruned       │ likes ≤ 1 after  │ Deleted from LinkedIn · agent         │
  │              │ 48h              │ explicitly avoids these patterns      │
  ├──────────────┼──────────────────┼───────────────────────────────────────┤
  │ New/pending  │ likes not yet    │ reinforcement=0 · not used in either  │
  │              │ fetched          │ signal                                │
  └──────────────┴──────────────────┴───────────────────────────────────────┘

  The key insight: the agent can still learn from engagement bait — it sees that
  the post resonated and can study the opening hook or framing — but it's
  explicitly told not to imitate the technical vagueness that caused the low
  quality score.
